Semua laporan tersimpan sebagai GitHub Issues, dan data sekolah tersimpan di berkas sekolah.json pada repository ini — sehingga sekolah dan pengawas melihat data yang sama.

Cara menyiapkan repository & token

  1. Buat repository baru di GitHub (boleh publik atau privat) dan aktifkan GitHub Pages seperti biasa.
  2. Di repository tersebut, buka tab Issues lalu pastikan fitur Issues aktif (Settings → Features → centang Issues).
  3. Tambahkan berkas sekolah.json berisi [] (array kosong) di root repository sebagai data sekolah awal.
  4. Setiap pengguna (pengawas maupun operator sekolah) membuat Fine-grained Personal Access Token miliknya sendiri di github.com/settings/tokens, dibatasi hanya untuk repository ini, dengan izin Issues: Read and write dan Contents: Read and write.
  5. Tempel token tersebut pada kolom di atas. Token hanya disimpan di peramban milik pengguna itu sendiri — tidak pernah dikirim ke server lain selain langsung ke api.github.com.

Peringatan keamanan: karena ini situs statis tanpa server, token tersimpan di localStorage peramban. Jangan gunakan token dengan akses penuh ke akun/repo lain — selalu buat fine-grained token yang dibatasi hanya pada repository ini.
